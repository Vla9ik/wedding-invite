# Приглашение на кыз узатуу — Нуржан

Статический сайт. Имя гостя берётся из ссылки — на Netlify ничего считать не нужно.

## Персональная ссылка

Откройте `/make.html`, введите имя и скопируйте ссылку:

```
https://ваш-сайт.netlify.app/?to=Анна
```

Имя появится в начале приглашения (без восклицательного знака) и в письме (со знаком).

## Что править

Имя, дата, адрес, карта и текст письма — в `src/config.js`.

- Фото в сердечке: `public/photos/bride.jpg`
- Три фото под календарём (PNG): `child-1.png`, `child-2.png`, `child-3.png`

## Запуск и Netlify

```bash
npm install
npm run dev
npm run build
```

На Netlify: сборка `npm run build`, папка `dist`.
